# Flip Search website

The public pages for Flip Search, hosted free with GitHub Pages:

- `index.html`: home page (use as the App Store **Marketing URL**)
- `support.html`: help and contact (the App Store **Support URL**)
- `privacy.html`: privacy policy (the App Store **Privacy Policy URL**)
- `app-ads.txt`: tells ad buyers which AdMob account may sell ads in the app

Before publishing:

1. Replace every `support@example.com` with your support email.
2. In `app-ads.txt`, replace the line with the one AdMob gives you
   (AdMob › Apps › View all apps › app-ads.txt). It contains your
   publisher ID, `pub-` followed by 16 digits.
3. Once the app is live, replace the `#` in the App Store button in
   `index.html` with the app's App Store link.

This repository must be named `<your-username>.github.io` so that
`app-ads.txt` sits at the root of the site, where AdMob looks for it.
